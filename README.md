Persian (fa_IR, RTL) WordPress + WooCommerce online stationery store.
Everything needed to rebuild the site lives in this repository ("site as code"):
Docker Compose dev environment + idempotent WP-CLI provisioning script + custom child block theme.
The database, uploads and secrets are never committed.
